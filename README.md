# Caregistry

Caregistry es una aplicación que te permite administrar tus vehículos y guardar su información localmente en el dispositivo.

### Requerimientos
- Cámara
- Un vehículo

### Funcionalidades
- Guardar, eliminar, ver y editar vehículos agregados.
- Guardado local de los vehículos.
- Tomar fotos dentro de la aplicación para los vehículos guardados.
